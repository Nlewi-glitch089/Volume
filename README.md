# Volume

A collection of software engineering coursework and technical exercises completed during training.

## Contents

- **App Features:** A planning exercise outlining the core features and system requirements for a learning platform.
- **Branching Strategy:** An exercise documenting Git branching conventions, feature development, and hotfix workflows.

## Purpose

This repository preserves technical exercises exploring software planning, project organization, and development workflows.

**Note:** These documents are coursework and planning exercises, not documentation for a completed application.
